# Event Mesh – Consumer Integration Flow

Dieses Paket enthält vier Entwicklungsstände des konsumierenden Integration Flows:

1. Event aus SAP Event Mesh empfangen  
2. CloudEvent auswerten und `OrderUUID` ermitteln  
3. Bestelldaten über den OData-Service nachladen  
4. Payload-Validierung und Exception Handling ergänzen  

Die ZIP-Dateien können in **SAP Integration Suite – Cloud Integration** importiert werden. Vor dem Ausführen müssen die Verbindungen zu Event Mesh und zum ABAP-System an die jeweilige Workshop-Umgebung angepasst werden.

Die Entwicklungsstände dienen als Sicherung und ermöglichen den Einstieg an jedem Punkt der Live-Demo.
