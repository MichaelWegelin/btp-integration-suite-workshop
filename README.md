# SAP Integration Suite Workshop

Dieses Repository enthält die Artefakte der Workshopreihe zur Integration Suite

## Inhalte

- `api-management/`: Workshop Teil 2: API Management
- `event-mesh/`: Workshop Teil 3: Event Mesh
- `integration-suite/`: Workshop Teil 1: Cloud Integration
- `slides/`: Vortragsfolien
- `src/`: RAP-Anwendung im SAP BTP ABAP Environment

## SAP Integration Suite bereitstellen

1. Integration-Suite-Entitlement dem Subaccount zuordnen.
2. Subscription anlegen.
3. Capabilities aktivieren: Build Integration Scenarios, Manage APIs, Manage Business Events
4. Benutzerrollen zuordnen.
5. Process Integration Runtime Serviceinstanz anlegen und Service Key erzeugen
7. Event Mesh Message Client Serviceinstanz anlegen und Service Key erzeugen.

## Eingehende und ausgehende Kommunikation im ABAP-System konfigurieren

1. RAP-OData-Service bereitstellen.
2. Communication Scenario entwickeln.
3. Communication User anlegen.
4. Communication System anlegen.
5. Communication Arrangements anlegen.
6. Security Material in der Integration Suite hinterlegen.
